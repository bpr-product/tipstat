# Put your coding-agent session history here before submitting

We read it to understand how you approached the problem (it's part of the design review
and the interview). Include only this project's sessions.

- **Claude Code:** session files are JSONL under `~/.claude/projects/<this-project-folder>/`. Copy them here.
- **Codex CLI:** sessions are under `~/.codex/sessions/`. Copy the ones from today.
- **OpenCode:** export the session (`/export` or the sessions folder) and copy it here.
- **Cursor / others:** export or copy-paste the chat into a .md file here.

Check the exact paths for your tool version; anything readable (JSONL, MD, TXT) works.
